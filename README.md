# AnimeKMP

Aplicación desarrollada con Kotlin Multiplatform que consume la API de Jikan para mostrar información de anime.

## Funciones principales

- Listado de anime
- Búsqueda
- Paginación
- Detalle de anime
- Favoritos
- Orden por puntuación, título y fecha
- Caché local
- Tema claro y oscuro

## Tecnologías utilizadas

- Kotlin Multiplatform
- Ktor
- SQLDelight
- Koin
- Jetpack Compose
- SwiftUI
- Jikan API

La lógica principal se encuentra en `shared`, mientras que Android utiliza Jetpack Compose y iOS utiliza SwiftUI.
